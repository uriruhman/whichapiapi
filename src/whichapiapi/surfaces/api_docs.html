Which API API

Обычный OpenAI-совместимый API, который сам выбирает модель под каждый запрос: по бенчмаркам нужной задачи и цене задачи с учётом «думания». Если модель не ответила, запрос уходит к запасной модели другого разработчика.

Подключение

Адрес (base URL)https://__HOST__/v1 или просто https://__HOST__
КлючAuthorization: Bearer wa-… — личный ключ выдаёт владелец
Модельauto — задача определяется по запросу

Codex / Claude Code: подключить как MCP (для тестировщиков)

Скопируйте это в Codex, вставив свой ключ вместо wa-…:

Подключи MCP-сервер Which API API. Добавь в ~/.codex/config.toml:

[mcp_servers.whichapiapi]
url = "https://__HOST__/mcp"
http_headers = { "Authorization" = "Bearer wa-…" }

Потом напомни мне перезапустить Codex. Когда выбираешь модель или API под задачу,
сначала спрашивай whichapiapi (suggest_candidates с with_scores). Если что-то
сломано, непонятно или не хватает — вызывай его report_feedback.

Claude Code: claude mcp add --transport http whichapiapi https://__HOST__/mcp --header "Authorization: Bearer wa-…"

Инструменты: suggest_candidates, rank_models, find_offers, compare_prices, estimate_cost, model_benchmarks, benchmark_boards, audit_n8n, route_chat, my_usage, report_feedback.

Python (openai)

from openai import OpenAI

client = OpenAI(base_url="https://__HOST__/v1", api_key="wa-…")
r = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Объясни, что такое трейсы"}],
)
print(r.choices[0].message.content)

curl

curl https://__HOST__/v1/chat/completions \
  -H "Authorization: Bearer wa-…" -H "Content-Type: application/json" \
  -d '{"model":"auto:coding","messages":[{"role":"user","content":"Напиши FizzBuzz на Rust"}]}'

Работает и в любых клиентах с «OpenAI-compatible» провайдером (Cline, Continue, Open WebUI, n8n, LibreChat): укажите base URL и ключ, модель — auto.

Как выбрать поведение

auto · auto:<задача> · auto:<задача>@<пресет>

Задачи: generalcodingmathagentsrussianwritinglong_contextvision

Пресеты: optimal баланс (по умолчанию) · best качество · value дёшево · fast быстро

Пример: auto:coding@best. Потоковый режим ("stream": true) поддерживается.

Что приходит в ответ

x-whichapiapi-routeкакая модель ответила, например openrouter:deepseek/deepseek-v4.1-flash
x-whichapiapi-taskкак был распознан запрос
x-whichapiapi-triedкакие модели пробовали по порядку (запасные)
x-whichapiapi-cost-usdсколько стоил этот запрос

Лимиты

  • У каждого ключа свой лимит в долларах. Остаток: GET https://__HOST__/v1/usage. На лимите — ошибка 402.
  • Ответ до 4096 токенов, до 20 запросов в минуту (ошибка 429).
  • Если общий баланс проекта на исходе, гостевые запросы временно ставятся на паузу (ошибка 503).
  • Ключ тестировщика пишет полные трейсы: тексты запросов и ответов, вызовы инструментов с аргументами — это видит владелец проекта, чтобы чинить и улучшать. Не отправляйте секреты и личные данные.
  • Инструменты MCP бесплатны; деньги с лимита тратит только сам чат (route_chat и /chat/completions).
